# The Dynamic Search for the Minimal Dynamic Extension Examples
This directory houses examples used in the submission to MTNS 2026.
Maple was the tool used for these examples.
The examples are presented in the `deds-conference-examples.pdf` file in more detail than found in the article.
The article claims that the examples require high-order dynamic precompensators for pure prolongations, and this claim is verified in full in `deds-conference-examples.pdf` by listing out the entire dynamic search performed.
All calculations are supported using the Dynamic-Extension, Dynamic-Search (DEDS) Maple package that was developed for this purpose.
The implementation of the package is `deds.mla` and the code print-out is in `DEDS.pdf`.
The sources of the worksheets end in `.mw`.
